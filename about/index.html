About

Aug 8, 2026

I'm a web developer who got into tech late but has always been interested in how things work. I enjoy tinkering with hardware, experimenting with software, and (sometimes) documenting what I learn along the way.

What I work with

I've spent time with old laptops, learning Linux, setting up home servers, customizing my espresso machine, and generally exploring what older or unconventional hardware can still do.

  • Photography: Astrophotography with an old 15-year-old Canon DSLR, automation with gphoto2 and shell scripts
  • Linux: Running different distros on vintage laptops, playing with proxmox as a home lab
  • Hardware: Arduino, ESP32, NAS setups on free laptops
  • Espresso machine: Customizing and automating my espresso machine
  • Home lab: Home Assistant, self-hosting services like Nextcloud and Plex, etc
  • Web development: Building things with ~~modern~~ web tools like this site and others
  • Other interests: Scuba diving, HEMA, lots...

This site

It's built with Astro, a modern static site generator. The aesthetic is intentionally minimal—just content, good typography, and plenty of darkspace (or whitespace if you're into that). No massive hero images or dark patterns. If you're interested in the code, it's on GitHub.

Get in touch

You can find my projects and code on GitHub. Feel free to open an issue or send a message if something interests you.
